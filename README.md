📊 Data Analytics Project 3 – SQL Data Analysis

🎯 Project Objective

This project focuses on analyzing an e-commerce orders dataset using SQL. The objective is to retrieve, filter, sort, group, and summarize order data to obtain useful insights.

🛠️ Tools Used

- 🐬 MySQL
- 💻 MySQL Workbench
- 🌐 GitHub
- 📗 Excel dataset

📂 Dataset

The dataset contains e-commerce order information, including:

- Order ID
- Date
- Customer ID
- Product
- Quantity
- Unit Price
- Shipping Address
- Payment Method
- Order Status
- Tracking Number
- Items in Cart
- Coupon Code
- Referral Source
- Total Price

📊 SQL Analysis Performed

The following SQL queries were performed:

1. Display all orders.
2. Filter orders based on specific conditions.
3. Sort orders by Total Price.
4. Count the total number of orders.
5. Count orders for each product.
6. Calculate total quantity sold for each product.
7. Use "HAVING" to filter products based on total quantity sold.
8. Use "SELECT", " WHERE", "GROUP BY", "ORDER BY" .
10. Count orders by payment method.
11. Count orders by order status analysing.
12. Count orders by referral source.
13. Calculate total sales for each order status.
